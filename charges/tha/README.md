# Pictures from the Book of Traceable Heraldic Art

Every picture in this folder comes from the **Book of Traceable Heraldic
Art**, https://heraldicart.org, an unofficial resource for the SCA edited by
Mathghamhain Ua Ruadháin. The collection is shared under the Creative Commons
**CC-BY-SA** licence: see https://heraldicart.org/credits for its terms. These
copies are shared under the same licence.

- **Who drew each one** is listed in [`../tha.csv`](../tha.csv): the artist,
  the source the collection took it from, and a link to its page in the
  collection. The search page shows these credits under any shield that uses
  one of the pictures.
- **What has been changed:** the numbers in each drawing are rounded to two
  decimal places to make the files smaller, and the very pale grey the
  insides are painted with is made white, so that the tools can paint a
  colour through it. Nothing else.
- **Do not edit these files or `tha.csv` by hand.** They are written by
  `tools/import_tha.py`, from the labels in `data/charges.csv` and the
  collection's own list of credits, https://heraldicart.org/entries.json.
  Pictures of our own go in `charges/art/` instead (see CONTRIBUTING.md).
